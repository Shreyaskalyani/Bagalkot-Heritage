# Bagalkot Heritage Tourism

Digital tourism platform for Badami, Pattadakal, Aihole, and the Chalukyan Heritage Valley in Bagalkot, Karnataka.

## Features

- 🏛️ **Monument Scanner & AI Heritage Guide**: Real-time identification and interactive audio guide.
- 🗺️ **Interactive Maps & 360° Panoramas**: Explore UNESCO World Heritage monuments in 360°.
- 🍛 **Cuisine & Culture Showcase**: North Karnataka local delicacies, traditions, and artisan crafts (Ilkal sarees, Guledgudda Khana).
- 💧 **Waterfalls & Natural Wonders**: Discover waterfalls across the Bagalkot district.
- 📅 **Curated Itineraries & Trip Planner**: Multi-day trip planner with interactive logistics.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Shreyaskalyani/Bagalkot-Heritage.git
   cd Bagalkot-Heritage
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Setup environment variables:
   Copy `.env.example` to `.env.local` and configure your API keys:
   ```bash
   cp .env.example .env.local
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
